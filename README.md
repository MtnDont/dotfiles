# My Personal Dotfiles
These are intended to be stored in $HOME/.config/ in most linux distributions

# Installation
```sh
$ git clone git@github.com:MtnDont/dotfiles.git
$ cd dotfiles.git
$ cp -r * $HOME/.config
```
